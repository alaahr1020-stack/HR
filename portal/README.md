# بورتال نيو جيزة — متابعة معاملات التأمينات الاجتماعية

بورتال ويب بالعربي (بهوية نيو جيزة — إدارة المدارس) لمتابعة الشغل بين **إدارة المدارس** و**شركة التأمينات** بس، من غير أي طرف تالت.

## بيعمل إيه

- **تسجيل كل معاملة**: استمارة 1 (اشتراك جديد)، استمارة 2 (تعديل أجر)، تعديل بيانات مؤمن عليه، استمارة 6 (انتهاء خدمة)، برنت تأميني، إصابة عمل، بيانات المنشأة، الكشف الشهري، وأي نموذج تاني. كل معاملة بتاخد رقم زي `NG-2026-0001`.
- **مراحل المتابعة**: مسجّل ← تم التسليم للشركة ← قيد التنفيذ ← مُقدَّم للتأمينات ← تم التسجيل. وفيه كمان "مطلوب استيفاء" و"مرفوض / ملغي".
- **سجل كامل لكل معاملة**: مين غيّر إيه وإمتى، والطرفين يقدروا يكتبوا لبعض تعليقات ويحطوا روابط مستندات. السجل ده مينفعش يتعدّل أو يتمسح.
- **لوحة متابعة**: الإجماليات، المعاملات المتأخرة (أكتر من 14 يوم)، والمطلوب من كل طرف.
- **بحث وفلترة** بالاسم أو الرقم القومي أو الرقم التأميني أو الحالة أو النموذج أو المدرسة.
- **طباعة إيصال استلام** لكل معاملة، و**كشف تسليم** لكذا معاملة مع بعض، وفيه خانات توقيع للطرفين.
- **تصدير Excel (CSV)**.
- شغال على الموبايل والكمبيوتر، وفيه وضع ليلي.

## تجربته فوراً (وضع تجريبي)

طول ما `firebaseConfig` في `js/config.js` فاضي، البورتال بيشتغل في وضع تجريبي، والبيانات بتتحفظ على جهازك بس.

```bash
cd portal
python3 -m http.server 8000
# افتح http://localhost:8000
```

## التشغيل الفعلي بين الطرفين (Firebase — مجاني)

1. اعمل مشروع على [console.firebase.google.com](https://console.firebase.google.com).
2. **Authentication** ← Sign-in method ← فعّل **Email/Password**.
3. **Firestore Database** ← Create database (Production mode).
4. **Project settings** ← Your apps ← أضف Web app، وانسخ `apiKey` و`authDomain` و`projectId` و`appId` في `portal/js/config.js`.
5. **قواعد الحماية**: انسخ محتوى `portal/firestore.rules` والصقه في Firestore ← Rules ← Publish. القواعد دي بتخلي البيانات متاحة بس للمستخدمين اللي انت فعّلتهم.
6. **إضافة المستخدمين** (بتتعمل منك انت بس):
   - في Authentication ← Users ← Add user (إيميل وباسورد لكل شخص).
   - انسخ الـ **User UID** بتاعه.
   - في Firestore اعمل collection اسمها `users` وجواها document اسمه نفس الـ UID، وفيه الحقول دي:

   | الحقل | النوع | القيمة |
   |---|---|---|
   | `name` | string | اسم الشخص |
   | `side` | string | `ng` لموظفي نيو جيزة، أو `partner` لموظفي الشركة |
   | `active` | boolean | `true` (وخليها `false` عشان توقف حد) |

7. **Authentication ← Settings ← Authorized domains**: أضف الدومين اللي هترفع عليه البورتال (مع GitHub Pages هيبقى `alaahr1020-stack.github.io`).

## الرفع على الإنترنت

- **GitHub Pages**: الـ workflow الموجود في `.github/workflows/deploy-portal.yml` بيرفع فولدر `portal` لوحده مع كل دمج على الفرع الرئيسي للريبو. فعّله من Settings ← Pages ← Source: **GitHub Actions**.
- أو **Firebase Hosting**: من جوه فولدر `portal` شغّل `firebase deploy` (الملف `firebase.json` جاهز).

> ملفات `firebaseConfig` مش سرية، والحماية كلها في `firestore.rules` وفي إن مفيش حد يقدر يدخل غير اللي انت ضفته.

## التخصيص

كل حاجة في `js/config.js`:
- `LOGO`: شعار نيو جيزة الرسمي. حط الملف في `portal/assets/` واكتب مساره.
- `SIDES`: أسماء الطرفين (اكتب اسم الشركة الحقيقي).
- `SCHOOLS`: أسماء المدارس.
- `FORM_TYPES`: أنواع الاستمارات والنماذج.
- `STATUSES` و`OVERDUE_DAYS`: المراحل، وعدد الأيام اللي بعدها المعاملة تعتبر متأخرة.

ألوان الهوية موجودة في أول `css/style.css` (`--brand` و`--accent`)، وتقدر تحط مكانها الألوان الرسمية.
